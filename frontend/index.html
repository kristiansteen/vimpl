API Reference

Full REST API for integrating Voice-to-BPMN outputs directly into vimpl boards, or building your own tooling on top.

Base URL
https://backend-eight-rho-46.vercel.app/api/v1
Configured via BACKEND_URL in frontend
Authentication
Authorization: Bearer <token>
Obtain via POST /auth/login
KEY ENDPOINT
POST  /boards/import
Imports a full project plan from Voice-to-BPMN in one atomic operation — creates the board, weekplan section, task post-its by track and week, risk matrix, and ideas matrix.
Body: { plan_name, process_name, duration_weeks, tracks[], tasks[], risks[], improvements[] }
Returns: { boardId, boardUrl, sectionId, tasksCreated }
